# 首次启动安装器基线

这里保留 R1 基线包中的 seed/setup/safe-mode 和对应隔离测试源码。
R1.1/R2 的后续集成另增加 product 中外部模块包的哈希校验和安装回退路径，
不能将本目录文件直接覆盖进已发布的 R2 镜像。

`test-bootstrap.py` 在 Linux 沙箱中模拟 Android 命令和重启，不操作真实设备。
它验证安装阶段、重启顺序、失败回退、安全模式及次数限制。
主机刷入脚本不包含私有设备参数。运行它们仍需完整的镜像、manifest 和工具依赖。

机型检查保留严格白名单；错误的 product 返回值会停止流程。
公开源码中的错误输出已补充实际 product，尚不等于已发布 ZIP 得到修复。
在确认反馈设备的真实型号和返回值前，不应删除这项检查或加入泛用平台别名。
