# TB371FC HyperOS project materials

本目录汇总本项目的内核、ROM 集成及模块文本源码和公开说明。
内核完整源码仍位于仓库根目录，不在这里重复复制。

| 目录 | 内容 |
| --- | --- |
| `kernel/` | #24 构建配置位置、源码对应关系和已验证镜像哈希 |
| `rom/` | 主机刷入脚本、首次启动安装器和 WPS 离线部署脚本 |
| `modules/` | 模块脚本、Java/C 源码、配置及模块属性 |
| `docs/` | 功能清单、安装流程、验证范围和脱敏规则 |

这是供阅读、审查和继续开发的源码资料集。模块原包中的 APK、SO、JAR、
固件等依赖不在这个文本导出中，因此不能把此目录直接压成可用模块。
模块目录保留其相对结构，原有源码许可证和版权标记继续适用。
来源与依赖需要结合原模块、上游项目和对应构建流程核对。

资料按功能筛选，未发布设备备份、账号数据、个人授权、聊天交接原文、
原始诊断日志、截图、设备序列号或本机路径。脱敏占位符不是实际配置值。

ROM 整包仍属于候选测试：静态检查、分区校验、安装状态机和隔离部署测试
不等于新整包清刷或首次 WPS 启动已完成实机验收。

感谢原移植基底作者兰微卡鱼及 Lenovo、小米、Linux、ReSukiSU/BakaSU 等上游贡献者。
