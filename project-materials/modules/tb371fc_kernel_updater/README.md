# TB371FC R8 内核更新器

模块安装和订阅更新本身不会刷写 boot。用户必须在模块操作页五分钟内连续确认两次，才会：

1. 校验机型、R8 构建、活动槽、当前 boot 与载荷哈希；
2. 将活动槽原 boot 备份到 `/sdcard/TB371FC-Kernel-Backups/`；
3. 写入并回读校验新 boot；
4. 等待用户手动重启。

新内核启动后再次连续确认两次，可恢复本模块记录的原 boot。模块不写另一槽，不修改 vbmeta、super、dtbo 或用户数据。

如果设备无法启动，模块无法自行运行回滚，必须使用保存的 boot 通过 fastboot 恢复。
