# PPS充电泵温度实验 v0.3-test — 未实测可用性

**未实测可用性。尚未证明能够启动充电泵、恢复正确温度或提高充电功率。**
这是第三版用户态消费链路原型，不是已验证的传感器/内核驱动修复。
此前固定PD条件下泵未启动，原始温度仍约135°C；PPS条件下尚未完成有效性测试。

## 安装和使用

仅适用于本项目TB371FC HyperOS3 R8，构建标识
`TB371FC-HyperOS3-20261103-full`，内核`4.19.325-perf++`及匹配的原厂
`hvdcp_opti`。需要BakaSU / KernelSU。安装器拒绝不匹配或已经挂载其他补丁的文件。

安装及重启均不会启用实验；模块没有service.sh或开机任务。
准备好支持PPS/APDO的电源，选择“正常充满”，保持15%–80%电量、电池温度15–40°C，
在模块管理器点击“操作”才会尝试一次限时测试。电源或温度条件不符会直接拒绝。
测试会短暂重启充电控制服务，并临时挂载实验文件。

测试最长约120秒，结束/收到退出信号时恢复原厂文件及原日志属性。
退出PPS、断电、切换充电模式、温度越界或达到85%前会提前结束。
日志：`/data/adb/tb371fc-pps-temp-test/logs/时间戳/`。

手动提前回退（root终端）：

```sh
su -M -c 'sh /data/adb/modules/tb371fc_pps_temp_test/rollback.sh'
```

卸载也会调用回退脚本。运行期间不要更新或禁用模块，应先回退；禁用标记不会
立即终止正在执行的手动操作。SIGKILL、内核卡死等不能保证退出处理执行，
可手动回退；重启也会清除临时挂载。未自动回退时保留运行日志和回退记录。
