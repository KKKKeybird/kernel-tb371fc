# v1.0-test1 实机验收 — 2026-11-14

范围：本项目R8 + HyperOS #25内核，当前5V/1.5A USB-PD电源；不是PPS开启充电泵的测试。

| 检查 | 结果 |
|---|---|
| 原厂charge_disable停充/恢复 | 通过：电池电流0、USB仍有输入；解除后恢复充电 |
| 原页面三个选项的点击及重新进入 | 通过：0正常、2健康保护、1旁路，勾选与底层一致 |
| 68%立即旁路 | 通过：电池电流0、USB输入约0.59–0.89A，未要求先充到80% |
| 正常/旁路往返 | 通过：正常时约0.4–1.3A充电，旁路时0 |
| 安装候选ZIP并重启 | 通过：约40秒boot_completed，旧init程序停止，模块自动接管 |
| 实际拔线再插回 | 通过：拔线时释放自身停充，接回后约1秒重新停充 |
| 亮屏/息屏 | 通过：两种状态均保持旁路；息屏时电池电流0，USB输入约0.26A |
| 禁用模块 | 通过：释放自身请求并恢复旧程序 |
| 重复启动 | 通过：同一实例，不产生第二个控制者 |
| SIGKILL子进程 | 通过：监督进程释放请求、恢复旧程序；重启桥接后正常 |
| 温控独立性 | 活跃时保留系统热限制9/10等变化；桥接源码不写热等级或输入暂停 |
| 与已装容量/系统兼容等模块 | 已共存启动、页面可用，无文件覆盖 |
| 80/78%阈值和回差 | 14项纯策略状态测试通过；未伪造实机SOC |

未验收：真实80%跨阈值、PPS泵开启、自动周期充满的完整日程、所有电源与高负载组合。
PPS停充后若泵仍开，或持续超过200mA充电，15秒后退出并回退。未修改JEITA或伪造传感器。
弱电源或开机负载超过输入能力时，电池可以补电；本模块不宣称物理断开电池。

底层是联想原厂独立停充接口，上层按小米选项适配；没有完整复刻ZUI的全部保养策略。
最终发布保留test1标签，避免把上述未验收范围当作正式承诺。

最终安装版空闲采样45.4秒：约0.59%单核CPU；一次内存快照PSS约49MiB（RSS含共享映射，不能当作独占内存）。不持有唤醒锁。该短时结果不等于长期耗电测量。
