# TB371FC R8 内核更新器

整合模块第一次安装时会自动执行以下流程，不需要用户再次点击：

1. 校验机型、R8 构建、活动槽、当前 boot 与载荷哈希；
2. 将活动槽原 boot 备份到 `/sdcard/TB371FC-Kernel-Backups/`；
3. 写入并回读校验新 boot；
4. 回读确认 `#25` 哈希后自动重启。

自动流程只有在模块安装提交成功后才开始。断网、载荷哈希不符、当前 boot
不在白名单、备份失败或写入后回读失败时都会停止，不自动重启，也不覆盖
boot。可以在模块操作页重试自动更新。

模块不写另一槽，不修改 vbmeta、super、dtbo 或用户数据。如果设备无法启动，
模块无法自行运行回滚，需要使用保存的 boot 通过 fastboot 恢复。
