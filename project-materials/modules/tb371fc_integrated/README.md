# TB371FC R8 整合维护与兼容修复 1.4.1

在 1.3-test1 的账户、分屏、手写笔、容量、音效和充电控制基础上，集成 v5 内核更新。
v5 保留 v4 的 PPS 温度和回读修复，并按原厂温度及协议条件恢复 Lenovo JEITA 恒流投票。

安装提交后，支持的旧 boot 会自动下载同一 Release 的 v5 镜像，核对哈希、备份活动槽、写入及回读成功后自动重启。已是 v5 的设备跳过写入、下载和自动重启。整合模块本身仍需重启才能加载新版本。

自动更新失败后可从模块操作页双确认重试。已由本版自动更新的设备，也可在操作页双确认恢复本次备份。此前独立内核更新器不必重复安装。
