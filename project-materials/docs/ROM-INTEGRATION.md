# ROM 集成流程

目标机型仅限 Lenovo TB371FC，系统基底为 HyperOS 3.0.4 / Android 15。

R1.1 为不预装 WPS 程序资源的常规版；R2 附带 WPS 客户端、干净 rootfs
和压缩 ext4 程序镜像。两版使用相同的新版 WPS 管理模块。

首次启动流程为：校验 payload → 准备 root 用户空间 → 启动完成后安装
meta-overlayfs → 完整重启 → 安装功能模块和运行时 → 完整重启 → 校验实际文件。
安装器包含安全模式、次数限制、备份及失败恢复。外部模块引用须受哈希校验保护。

R2 使用用户态解压和只读 ext4 挂载，不要求改用 EROFS 内核驱动。
R2 的 vendor 分区向 super 原空闲区扩大 2GiB，更新主备 LP 元数据及校验；
super 总大小仍为 12GiB。原始 ROM 必须单独合法获取，本资料集不包含完整镜像。

刷入脚本是完整线刷流程，会更新底层与系统分区。默认只读校验、型号和分区检查
不能替代人工确认硬件及备份数据。首次安装、跨底包迁移和保数据升级应按版本说明操作。

本目录不提供设备个人备份、ADB 配对密钥、私有授权或可公开的解锁信息。

安全边界：安装器以镜像内预置的校验元数据和 payload 为可信输入，不是通用的
不可信 ZIP 安装服务。重新构建时还应校验归档成员的相对路径、链接及模块 ID，
避免路径穿越；不能仅依赖 `tb371fc_*` 前缀。基线源码保留原行为，未将该边界
包装为已实现的运行时隔离保护。
