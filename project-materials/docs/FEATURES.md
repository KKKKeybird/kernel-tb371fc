# 功能概览

- 内核：笔休眠充电、键盘状态包唤醒修复、统一四通道 DSP 矩阵、
  mi_asap、thermal_message、uclamp、原生内存扩展回写与 lz4kd。
- 音频：单声道复制、双声道展开、四轨独立输出、显示旋转回调和矩阵淡化。
- 输入：原生蓝牙笔连接与设备分类、触控笔压感、键盘霍尔消抖、触控板轻触点按。
- 电源：合盖防亮屏、未充电合盖省电、开盖恢复。
- 系统：TouchFeature 兼容接口、VINTF、部分 HAL 崩溃循环与媒体兼容适配。
- 显示：最高刷新率为 120Hz，保留自动刷新率调度。
- WPS：R2 提供客户端和 ext4 运行资源，模块兼容旧目录式运行环境；
  正常退出时通过属性事件清理残留的 Android 前台服务。

已知边界：小米查找、完整云备份、叠加模糊性能和 144Hz 笔兼容仍有未解决项。
SELinux 使用 Permissive。正常退出后的 WPS 服务清理已有实测，刚打开便立即
强杀的极端竞态不作为已保证场景。
